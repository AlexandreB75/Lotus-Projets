# Script — Primeiro Atendimento (WhatsApp/DM)

> Baseado em [[03-Squads/Instagram-Imoveis/Treinamento-Kaka-HKnove/Notas-Completas|Treinamento Kaká]] Bloco 3 (Qualificação) e Bloco 2 (Venda de Marca)

---

## PASSO 1 — Abertura (primeiras mensagens)

> Objetivo: criar rapport antes de falar de produto

**Mensagem 1:**
```
Oi [Nome]! Tudo certo por aí?
Vi que você demonstrou interesse no Lotus Business.
Posso te contar um pouco sobre o projeto?
```

**Mensagem 2 (após resposta positiva):**
```
Perfeito. Antes de qualquer coisa, me conta — você é de qual cidade?
```

---

## PASSO 2 — Qualificação rápida

> Objetivo: criar percepção de oportunidade comparando com o mercado dele

**Após saber a cidade:**
```
Legal! Lá em [cidade], um apartamento ou sala comercial boa
custa em torno de quanto? Você tem ideia?
```

**Após resposta (usar para criar contraste):**
```
Faz sentido. Olha só o que está acontecendo aqui em Itapema:
Samsung, grandes empresas estão se instalando na região.

Enquanto o mercado de [cidade] está estabilizado,
aqui a valorização já está acontecendo.

E o melhor: dá pra transformar isso em renda todo mês.
```

---

## PASSO 3 — Apresentar o produto como ativo

> Objetivo: mudar o frame de "compra de imóvel" para "investimento que gera renda"

```
O Lotus Business não é um imóvel comum.
É um ativo que trabalha pra você.

Uma sala de 60m² ali gera R$ 6.000 por mês de aluguel.
Uma de 170m² chega a R$ 17.000 por mês.

Você não compra tamanho. Você compra renda.

Qual o aluguel que faria sentido receber todo mês pra você?
```

---

## PASSO 4 — Convidar para apresentação com o casal

> Regra: NUNCA marcar só com o homem

```
Quero te apresentar o projeto direito, com todos os detalhes.

Só que eu explico uma vez só. Você consegue vir com sua esposa/sócio?
Assim vocês decidem juntos com informação completa.

Qual o melhor dia pra vocês essa semana?
```

---

## PASSO 5 — Se pedir preço antes da apresentação

```
O valor depende do tamanho da sala e da renda que você quer gerar.

Salas a partir de 60m², com renda de R$ 6.000 a R$ 17.000/mês.

Mas o número só faz sentido depois que você entender o projeto.
Garanto que a apresentação vale o seu tempo.

Podemos marcar?
```

---

## Lembretes rápidos
- Nunca falar de preço antes de criar valor
- Sempre perguntar de onde é o cliente (qualificação)
- Insistir no casal — sem esposa/sócio, a chance de fechar cai muito
- Quando a venda estiver feita: **pare de falar**

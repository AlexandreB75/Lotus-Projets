# Implantacao n8n - Sistema Hermes

Esta area organiza os workflows em duas classes:

- `ajustados-producao/`: artefatos verificados, corrigidos ou publicados.
- `reserva/`: candidatos a arquivo, fallback ou comparacao.

Nao e uma area para excluir arquivos. E uma area de governanca para saber o que esta pronto e o que esta fora do caminho principal.

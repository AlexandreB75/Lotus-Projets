## Roteamento por demanda

| Demanda | Agente principal | Task |
|---|---|---|
| Criativo para Meta Ads | `visual-generator` + `design-chief` | `audit-design` / `review` |
| Post / Story Instagram | `visual-generator` | `review` |
| Apresentação de produto (pitch deck) | `dan-mall` + `ux-designer` | `generate-handoff` |
| Material para evento | `visual-generator` + `design-chief` | `create-component-spec` |
| Sistema de design / guia visual | `design-system-architect` | `create-design-system` |
| UX de landing page | `ux-designer` + `brad-frost` | `design-ux-flow` |
| Diagnóstico de material fraco | `design-chief` | `diagnose` |

**Para Hilton (premium/anti-hype):** visual limpo, paleta sóbria, espaço negativo — sem excesso de elementos. `david-ogilvy` (Copy) define o tom; `design-chief` + `dan-mall` executam o visual.

**Para Lótus Business (corporativo/ROI):** visual moderno e direto, dados em evidência (rentabilidade, localização, infraestrutura). `visual-generator` para criativos de anúncio.

## Agentes disponíveis (8)

- **design-chief** — orquestrador, diagnóstico, qualidade final
- **visual-generator** — criação de criativos, posts, stories ← principal para anúncios
- **ux-designer** — fluxo de usuário, landing page, jornada
- **design-system-architect** — sistema de design, componentes, consistência
- **ui-engineer** — implementação técnica de UI
- **dan-mall** — design de apresentações e pitch decks ← apresentações Hilton/Lótus
- **brad-frost** — atomic design, componentes reutilizáveis
- **dave-malouf** — estratégia de design e design ops

# Task — Criar Roteiro de Reel

## Input necessário

- Projeto: Hilton ou Lótus Business
- Público-alvo: médico / investidor / empresário / clínica
- Ângulo: renda / marca / urgência / exclusividade
- Duração: 15s / 30s / 60s

## Entrega

Roteiro completo com:
1. Gancho (0–3s)
2. Desenvolvimento (3–25s)
3. Virada
4. CTA

## Critério de qualidade

- Gancho para o scroll nos primeiros 2 segundos
- Sem menção de preço
- CTA único e claro
- Tom adequado ao público (investidor ≠ médico ≠ empresário)

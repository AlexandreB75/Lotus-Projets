# Squad — Oferta Hormozi

## Função

Estruturar ofertas comerciais com alto valor percebido, clareza de proposta e motivo real para o lead avançar.

Este squad é uma referência de estratégia de oferta. Não é um agente separado obrigatório.

---

## Quando usar

- Criar campanha de captação.
- Melhorar uma landing page.
- Tornar um anúncio mais forte.
- Criar proposta comercial mais clara.
- Reposicionar um produto que está parecendo genérico.
- Construir argumento de valor para Hilton, Centro Médico, Lótus ou The Spot.

## Estrutura de oferta

Toda oferta deve responder:

1. Para quem é?
2. Qual problema ou desejo resolve?
3. Por que esse produto é diferente?
4. Qual ganho potencial o cliente percebe?
5. Qual risco ou objeção precisa ser reduzido?
6. Qual próximo passo simples?

---

## Saídas práticas

- Proposta de valor.
- Ângulo de campanha.
- Headline para anúncio.
- CTA para WhatsApp.
- Estrutura de landing page.
- Argumento de fechamento.

---

## Regras comerciais

- Não criar promessa impossível.
- Não vender garantia de renda, valorização ou liquidez.
- Transformar características em valor percebido.
- Reduzir fricção para o próximo passo.
- Oferta boa precisa ser simples de entender e fácil de agir.

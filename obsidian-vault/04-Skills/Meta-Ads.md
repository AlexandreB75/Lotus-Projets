# Skill — Meta Ads: Tráfego Pago

## O que é

Meta Ads é a plataforma de anúncios do Facebook e Instagram. Permite criar campanhas segmentadas para públicos específicos.

## Estrutura de Campanha

```
Campanha (objetivo)
  └── Conjunto de Anúncios (público + verba)
        └── Anúncio (criativo + copy)
```

### Objetivos Mais Usados
- **Leads** — formulário nativo do Meta (Lead Ads)
- **Tráfego** — direciona para landing page
- **Conversões** — otimiza para ação no site (Pixel)
- **Alcance** — maximiza visualizações

---

## Públicos

### Públicos Frios (topo de funil)
- Interesse: investimento, imóveis, empreendedorismo
- Lookalike de clientes atuais (1-3%)
- Segmentação geográfica (cidade-alvo)

### Públicos Quentes (fundo de funil)
- Visitantes do site (Pixel)
- Engajamentos no Instagram
- Leads que não converteram
- Clientes atuais (para upsell)

---

## Boas Práticas

- Testar **3 criativos** por conjunto de anúncios
- Orçamento mínimo: R$ 30/dia por conjunto
- Deixar rodar **3-5 dias** antes de otimizar
- **Nunca pausar** campanha que está convertendo
- Usar **UTMs** para rastrear no HubSpot

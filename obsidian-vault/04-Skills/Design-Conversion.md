# Design para Conversão

## Responsabilidades

- Criar peças visuais para Instagram, Meta Ads e WhatsApp
- Desenvolver e otimizar landing pages de conversão
- Manter identidade visual Lotus + Hilton
- Produzir materiais de suporte a vendas (decks, folders)

## Princípios de Design para Conversão

| Princípio | Aplicação |
|-----------|-----------|
| Hierarquia visual | CTA acima da dobra, headline em destaque |
| Contraste | Botão em cor oposta ao fundo |
| Prova social | Fotos reais, depoimentos, números |
| Velocidade | Imagens <200kb, LCP <2.5s |
| Mobile-first | 70%+ do tráfego é mobile |

## Especificações por Formato

### Instagram Feed
- 1080x1080px (quadrado) ou 1080x1350px (retrato)
- Texto máximo 20% da imagem para Meta Ads
- Paleta: [tons Lotus / Hilton conforme briefing]

### Stories / Reels
- 1080x1920px
- Texto nos primeiros 3 segundos
- CTA claro no último frame

### Landing Page — Estrutura
```
[Hero: headline + CTA principal]
[Benefícios: 3 ícones]
[Prova social: fotos + números]
[Objeções respondidas]
[CTA secundário]
[Footer com contato]
```

## Ferramentas

- Canva Pro (peças rápidas)
- Figma (landing pages)
- CapCut (Reels e vídeos curtos)

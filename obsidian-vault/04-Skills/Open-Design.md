# Skill — Open Design: Capacidades de Design e Criativo

## O que é o Open Design

Plugin com +140 skills de design, criativo e produção visual integrado ao Claude Code. Substitui fluxos manuais de Canva, Figma e ferramentas de edição para gerar materiais com velocidade.

## Como usar

Skills do open-design são ativadas via `/` no Claude Code. Exemplos:
- `/ad-creative` — briefing → creativo finalizado
- `/figma-generate-design` — descrição → design no Figma
- `/pptx-generator` — conteúdo → apresentação .pptx

# Skill Builder Operacional

> Antigo conceito: `opensquads-skill-creator`.

## Função

Transformar conhecimento comercial solto em skills operacionais reutilizáveis para o OpenBotXD.

---

## Objetivo

Evitar que materiais importantes fiquem apenas como notas soltas no Obsidian.

O Skill Builder Operacional transforma materiais validados em procedimentos repetíveis, com:

- objetivo claro;
- quando usar;
- regras de execução;
- entradas necessárias;
- saída esperada;
- cuidados comerciais;
- links para projeto/agente responsável.

---

## Regra de criação

Só criar uma skill quando ela resolver uma rotina repetida ou estrategicamente importante.

Evitar criar skill por estética ou excesso de organização.

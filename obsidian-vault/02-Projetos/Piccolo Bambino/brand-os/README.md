# Brand OS — Piccolo Bambino

Sistema modular de referência de marca. Carregue os arquivos relevantes como contexto antes de qualquer tarefa de marketing.

---

## Como usar

**Para gerar copy de anúncio Meta Ads:**
Carregue `foundation` + `voice` + `craft/meta-ads`

**Para criar caption de Instagram:**
Carregue `foundation` + `voice` + `craft/instagram`

**Para estruturar conversa de WhatsApp:**
Carregue `foundation` + `voice` + `craft/whatsapp`

**Para posicionamento ou estratégia de campanha:**
Carregue `foundation` + `voice` + `positioning`

---

## Estrutura

```
brand-os/
├── foundation.md       ← quem somos, público, proposta de valor, dados de performance
├── voice.md            ← tom, atributos, antipadrões, registro por canal
├── positioning.md      ← diferencial vs. concorrentes, hierarquia de mensagens
└── craft/
    ├── meta-ads.md     ← estrutura de copy, ângulos, regras, configuração de ad set
    ├── instagram.md    ← tipos de conteúdo, regras de caption, frequência, hashtags
    └── whatsapp.md     ← fluxo de conversa, templates por situação, indicadores
```

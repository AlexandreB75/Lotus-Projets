# Scripts WhatsApp — Residencial Pool

---

## Script 01 — Alinhamento operacional (proprietário atual)

Fulano, estamos iniciando o alinhamento operacional das unidades residenciais do Hilton Garden Inn Itapema.

Quero entender como você pretende deixar sua unidade:

- uso próprio
- locação particular
- participação no pool administrado

Caso tenha interesse no pool Hilton, a unidade precisará seguir o padrão de mobília exigido pela bandeira para manter o padrão internacional do empreendimento.

Também preciso confirmar se a unidade permanecerá no mesmo CPF ou será transferida para holding/empresa — essa organização antecipada evita correria próxima da entrega.

Quando ficaria melhor pra conversarmos?

## Script 03 — Lead casal/família (uso + renda)

Olá, [Nome].

Uma coisa que chama atenção no residencial do Hilton é a flexibilidade: você pode usar quando quiser e colocar no pool nos períodos que não está usando.

Não é uma decisão definitiva — você escolhe como quer operar. O que muda é que, no pool, a unidade precisa seguir o padrão Hilton de mobília.

Você está pensando mais em usar, em renda, ou numa combinação dos dois?

## Script 04 — Contorno da objeção "não será entregue mobiliado"

Entendo, [Nome].

O residencial realmente não é entregue mobiliado — diferente das unidades do hotel.

O que acontece é que, para quem quiser entrar no pool Hilton, existe um processo de homologação de mobília junto à bandeira. Já estamos mapeando fornecedores parceiros para facilitar esse processo.

Para quem vai usar como residência própria ou locação particular, a mobília é totalmente por conta do proprietário, sem restrição de padrão.

Qual é a sua intenção para a unidade?

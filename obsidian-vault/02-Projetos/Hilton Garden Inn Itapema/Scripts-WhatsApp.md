# Scripts WhatsApp — Hilton Garden Inn Itapema

> Objetivo: fluxo completo de atendimento para leads do Hilton Garden Inn Itapema, com linguagem natural, consultiva e comercial.

---

## Princípio do Atendimento

Não começar mandando tabela.

Primeiro entender:

1. Quem é o lead
2. O que ele busca
3. Se conhece Itapema
4. Se está sozinho ou decide com família/cônjuge
5. Se está olhando investimento, uso ou valorização
6. Qual nível de urgência

**Regra central:**

> Antes de vender a tese, entender o estado emocional do lead.
>
> A ordem correta é: validar → diagnosticar → reduzir defesa → perguntar → só depois apresentar Hilton.

**Não começar com:**

- tabela
- PDF
- reunião
- “oportunidade”
- valorização
- diferenciais do empreendimento

**Começar com:**

- “Faz sentido.”
- “Entendo sua trava.”
- “Antes de te falar do projeto...”
- “Seu foco seria valorização, renda ou uso pessoal?”
- “O que mais ficou na sua cabeça?”

## 1. Lead Frio

### Objetivo

Tirar o lead da curiosidade e descobrir motivação real.

### Mensagem 1 — abertura

```
Oi, [Nome]. Tudo bem?

Vi que você demonstrou interesse no Hilton Garden Inn Itapema.

Antes de te mandar um monte de informação, deixa eu entender rapidinho:
você está olhando mais como investimento, para uso da família ou por valorização em Itapema?
```

### Se responder “só queria saber mais”

```
Perfeito.

Vou te resumir de forma simples: o Hilton Garden Inn Itapema não é um imóvel comum.

Ele junta uma cidade muito forte do litoral catarinense com uma marca internacional. Então a conversa não é só metragem e preço — é posicionamento, patrimônio, uso e potencial de valorização.

Você já conhece Itapema ou ainda está começando a olhar a região?
```

### Se não responder

Aguardar. Não insistir no mesmo dia com textão.

## 2. Lead Investidor

### Objetivo

Levar a conversa para tese patrimonial, não para emoção pura.

### Diagnóstico

```
Legal, [Nome]. Para eu te orientar certo: você olha mais para renda, valorização ou proteção de patrimônio?
```

```
Hoje você costuma investir mais em imóvel, renda fixa, empresa ou outros ativos?
```

### Pitch

```
Para investidor, eu gosto de olhar esse projeto de forma bem objetiva.

Você tem três forças juntas:

1. Itapema, uma cidade em crescimento e valorização;
2. Hilton, uma marca internacional que aumenta confiança e percepção de valor;
3. Um produto imobiliário com potencial de uso, renda e patrimônio.

Então não é uma compra para comparar só por metro quadrado. É uma tese de posicionamento.
```

### Condução

```
Se fizer sentido para você, eu te mostro primeiro a lógica do projeto e depois as opções disponíveis.

Você prefere olhar mais a parte de valorização ou a parte de renda potencial?
```

### Fechamento implícito

```
Pelo seu perfil, faz sentido olhar as unidades mais estratégicas, não necessariamente qualquer opção.

Quer que eu te envie uma seleção mais voltada para investimento?
```

## 3. Lead Casal

Trazer cônjuge/família para a decisão e evitar venda quebrada.

### Diagnóstico

```
Esse tipo de decisão normalmente envolve a família também.

Você está olhando sozinho por enquanto ou sua esposa/marido também participa da decisão?
```

### Pitch

```
Para casal, eu gosto de apresentar o Hilton de um jeito bem claro.

Não é só investimento frio. É patrimônio com significado.

Você tem Itapema, que é uma cidade desejada; tem a marca Hilton, que traz segurança e padrão; e tem a possibilidade de unir uso, valorização e patrimônio para a família.

Por isso eu prefiro apresentar para os dois juntos. Evita ruído e vocês conseguem decidir com a mesma informação.

### Condução

```
Faz sentido eu marcar uma apresentação rápida com vocês dois?

Em 15 minutos eu mostro a tese, o projeto e as opções que mais combinam com o perfil de vocês.
```

### Se disser “vou falar com ela/ele”

```
Perfeito. Melhor mesmo decidir junto.

Para facilitar, posso te mandar um resumo curto para você encaminhar e depois marcamos um horário com vocês dois.
```

Resumo para encaminhar:

```
Resumo rápido: Hilton Garden Inn Itapema é um projeto com marca internacional em uma das cidades mais valorizadas do litoral catarinense.

A tese é unir patrimônio, uso, renda potencial e valorização em Itapema.

Vale olharmos juntos para entender se faz sentido para nossa família.

## 4. Lead Premium

### Objetivo

Não vender preço. Vender posicionamento, marca e exclusividade percebida.

### Diagnóstico

```
[Nome], pelo seu perfil, imagino que você não esteja buscando simplesmente o imóvel mais barato.

Você olha mais para localização, marca, exclusividade ou potencial de valorização?
```

### Pitch

```
Esse produto é para quem entende posicionamento.

O Hilton Garden Inn Itapema não entra na mesma comparação de um imóvel comum, porque existe uma marca internacional por trás e uma cidade em forte valorização.

Cliente premium normalmente compra o conjunto: marca, segurança, padrão, localização e percepção de valor.

Aqui a pergunta não é só “quanto custa?”. A pergunta é: “faz sentido ter uma posição em Itapema com assinatura Hilton?”
```

### Condução

```
Se você quiser, eu não te mando todas as opções.

Eu filtro as que fazem mais sentido para o seu perfil e te mostro só o que realmente vale olhar.
```

### Fechamento implícito

```
Prefere que eu te apresente uma opção mais estratégica para investimento ou uma opção mais premium para uso e valorização?
```

## 5. Lead Comparando Balneário Camboriú

### Objetivo

Não atacar BC. Reposicionar Itapema como oportunidade antes da maturação total.

### Diagnóstico

```
Você está comparando com Balneário Camboriú mais por segurança, valorização ou liquidez?
```

### Resposta estratégica

```
Faz todo sentido comparar com BC. Balneário já é um mercado muito consolidado.

A diferença é que, em muitos casos, quando uma cidade já virou consenso, boa parte da valorização já aconteceu.

Itapema está em outro momento: ainda tem movimento de crescimento, desejo aumentando e entrada de projetos mais fortes.

Então a análise não é “Itapema contra BC”. É entender onde ainda existe mais espaço de valorização e melhor ponto de entrada.
```

### Conexão com Hilton

```
E quando você soma Itapema com uma marca como Hilton, a tese fica mais forte.

Porque não é qualquer produto em Itapema. É um ativo com assinatura internacional dentro de uma cidade que ainda está ganhando força.
```

### Fechamento implícito

```
Se você já gosta de BC, vale olhar Itapema com atenção justamente pelo momento de entrada.

Quer que eu te mostre a diferença de tese entre comprar em mercado já consolidado e entrar em uma cidade ainda em expansão?
```

## 6. Lead Sem Urgência

### Objetivo

Criar consciência de timing sem parecer pressão.

### Diagnóstico

```
Entendi. Você está olhando mais para médio/longo prazo ou só acompanhando oportunidades por enquanto?
```

### Resposta

```
Sem problema nenhum olhar sem pressa.

Só gosto de separar uma coisa: não ter pressa é diferente de perder timing.

Em produto imobiliário bom, principalmente com marca forte e cidade em valorização, as melhores posições normalmente saem antes.

Então meu papel não é te pressionar. É te mostrar o cenário para você decidir com informação.
```

### Condução

```
Faz sentido eu te mandar um resumo simples da tese e, se você gostar, depois olhamos as opções com calma?
```

### Fechamento implícito

```
O próximo passo não é comprar. É só entender se essa oportunidade merece ficar no seu radar agora.
```

## 10. Pós-Visita / Pós-Apresentação

### Objetivo

Consolidar valor, tratar dúvidas e conduzir próximo passo.

### Mensagem logo após

```
[Nome], obrigado pelo tempo hoje.

Pelo que conversamos, vejo que o ponto principal para você é [investimento/uso da família/valorização/segurança].

O Hilton faz sentido justamente porque junta Itapema, marca internacional e uma proposta patrimonial diferente de um imóvel comum.
```

### Recap objetivo

```
Resumo do que vimos:

1. Itapema em valorização;
2. marca Hilton como diferencial;
3. produto com uso e renda potencial;
4. posicionamento premium;
5. opções que podem encaixar no seu perfil.

A próxima etapa é entender qual unidade/condição conversa melhor com seu objetivo.
```

### Pergunta de avanço

```
Depois do que você viu, o que ficou mais forte para você: a tese de valorização, o uso pela família ou a possibilidade de renda?
```

### Se demonstrou interesse

```
Pelo seu perfil, eu não deixaria para olhar todas as opções depois.

Vamos separar 2 ou 3 unidades que realmente fazem sentido e avaliar com calma?
```

### Se ficou em dúvida

```
Normal ficar com dúvida. É uma decisão importante.

Me diz só uma coisa: sua dúvida hoje é mais sobre o projeto, sobre valores/condição ou sobre o momento certo de decidir?
```

### Se precisa falar com família

```
Perfeito. Melhor decidir junto.

Quer que eu monte um resumo curto para você encaminhar para sua esposa/família com os pontos principais?

Assim vocês conversam com a mesma informação.
```

## 12. Regra de Ouro

Nunca encerrar a conversa sem uma próxima ação clara.

Sempre sair com uma dessas opções:

- enviar resumo
- agendar apresentação
- envolver cônjuge/família
- separar opções
- retornar em data combinada
- colocar em stand-by com permissão

**Frase útil:**

```
Para eu te acompanhar do jeito certo, qual próximo passo faz mais sentido: te mandar um resumo, agendar uma apresentação ou deixar para retomar mais para frente?
```

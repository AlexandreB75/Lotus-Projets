> ### Como usar no Meta Ads
> 1. Acesse o **Gerenciador de Anúncios** → Públicos → Criar Público → **Público Personalizado**
> 2. Selecione a fonte: **Lista de Clientes**
> 3. Faça o upload dos dados no formato CSV usando os campos: `phone`, `fn` (first name), `city`, `st` (state), `country`, `zip`
> 4. O Meta vai cruzar os telefones com perfis do Facebook/Instagram via hash
> 5. Com esse público ativo, crie um **Lookalike Audience** (1-3%) para escalar
> 
> **Coluna prioritária para match:** `Telefone` — o Meta aceita no formato `+55DDNÚMERO`

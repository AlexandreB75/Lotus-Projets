# Política de Organização do Vault

1. Materiais novos vão primeiro para [[08-Raw/00-INDEX-Raw|08-Raw]].
2. Cada projeto ativo deve ter um `MASTER` ou `00-INDEX` como ponto de entrada.
3. Código e repositórios ficam fora do vault.
4. Não apagar automaticamente: arquivar antes de qualquer exclusão.
5. O Vault Librarian apenas detecta e relata; não move, funde nem exclui conteúdo.
6. Fazer revisão semanal de Inbox/[[08-Raw/00-INDEX-Raw|08-Raw]], links internos e notas órfãs.

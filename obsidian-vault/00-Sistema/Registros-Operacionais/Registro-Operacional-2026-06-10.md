## 4. OpenClaw + Ollama + OpenAI

Foi instalado e testado o Ollama local no servidor.

Arquivo de referência:

- [[06-Scripts/OpenClaw/Ollama-Local-Servidor-2026-06-10|Ollama Local no Servidor — 2026-06-10]]

Status técnico:

- Ollama instalado em modo usuário no servidor.
- API local: `http://127.0.0.1:11434`.
- Modelos baixados:
  - `llama3.2:1b`
  - `llama3.2:3b`
- OpenClaw reconheceu os modelos:
  - `ollama/llama3.2:1b`
  - `ollama/llama3.2:3b`

Conclusão prática:

- O Ollama funciona para testes diretos e tarefas simples.
- Não ficou adequado como modelo principal do OpenClaw neste ambiente.
- Motivos: execução em CPU, limite real de memória/container e overflow de contexto em subagents.
- Recomendação: manter OpenAI como modelo principal.
- Para reduzir custo, a sessão foi trocada de `openai/gpt-5.5` para `openai/gpt-4.1`.

## 6. Observação de compliance

Materiais comerciais devem evitar promessa de:

- valorização garantida;
- rentabilidade garantida;
- ocupação garantida;
- renda garantida;
- revenda garantida;
- intercâmbio garantido.

Usar sempre linguagem de potencial, contexto, possibilidade e dados históricos quando aplicável.
